Working in the grids

Steps 1, 2 and 3 each have a spreadsheet-style grid under the plan. You can build a whole rig from the grids alone - typing straight from a drawing or pasting from Excel - or use them alongside the plan and side panel. Every edit in a grid is exactly the same as making it in the side panel, and each edit (or paste) is one Undo step.

Grey columns are results or values set elsewhere (for example the position of a bolted truss); you cannot type in them. A column that is grey for one row may be editable in another.

Adding rows

The last row of each group is a "new" row in italics: new truss… (type a name), + load on North (start typing), + hoist on West (type its position). Click one of its editable cells and type: a new truss, load or hoist is created with what you typed, and the cursor stays on the new row so you can keep going.

Picking from a list

Some cells search a list as you type - the truss Type, the load Item / fixture and the Hoist model. Type any part of the name (several words narrow it down: jte 12 plated, mac aura, lode 1t). Use the arrow keys to choose, then Enter to pick, or Tab to pick and move to the next cell. Esc closes the list.

Pasting from a spreadsheet

Copy a block of cells in Excel (or any spreadsheet), click the cell where the top-left value should go, and press Ctrl+V. Each line fills a row, from that cell to the right and down. If you run past the last row of a group, new rows are added to it. Empty pasted cells leave the value alone; cells the app cannot read are skipped and it tells you how many. Paste one value (no tabs) to put it in the selected cell.

Column order for pasting

Loads: At, From, Item, Weight, Clamp, Mirror, Note, Category (Mirror: yes, y, x or 1).
Hoists: At, From, Hoist, Chain / rope, DLF, Hardware, Hangs from, Level.
Start the paste in the At column. Put the column you start in first in your spreadsheet selection.

Choosing several hoists at once

The Hoists grid (step 3) lets you change many hoists in one go - see Editing many hoists at once.

Step 1 - Structure

In step 1 you create every truss, set its make, model and length, add its corner blocks, place it on the plan and bolt the trusses together. Build all the trusses first; loads and hoists come later.

Adding a truss

Click + Truss (above the plan, or in the rig panel), or type a name in the grid's new truss… row. A new truss is a 20 ft JTE 12x12 Plated, named Truss 1, Truss 2…, measured from its centerline, with no loads and no hoists, placed at X 0, Y 0 running east. It is selected, so the side panel shows it.

[[img truss-head.jpg|The top of a truss's panel: name, status, type, length, what it hangs from, and actions.|70]]

The top of the truss panel shows:

  • the name (click it to rename) and its status;
  • its type and length, and Hangs from: the trusses or corner blocks it is bolted to and how many hoists it has;
  • buttons: + Hoist (adds a hoist in the middle), + Load (jumps to the quick-add box), Bolt to…, Connected, rotate ⟳ (free trusses only), Duplicate and Delete.

Connected dims everything on the plan that is not joined to this truss (bolted, stacked, or hung on a hoist below it) - a quick way to spot a truss you meant to bolt on but did not. Click it again to turn it off.

Choosing the truss type

Open the Truss section. Choose the Manufacturer, then the Model.

  • Models marked (MFG) use the manufacturer's own current load table and are listed first. The others come from the original Truss Load Analyzer workbook. Where a workbook row allows more than the maker's current table for a span in your rig, the app warns and names the maker's row to use instead.
  • (metric data) means the maker publishes a metric table; it is checked in whole-metre steps.
  • (custom) is a truss you added yourself (see Databases).

Under the pickers the app shows the maximum span, the maximum cantilever (a quarter of the maximum span), the repetitive-use factor applied, and where the data comes from. For manufacturer data, maker's load table ↗ opens the maker's own document in a new tab (this needs an internet connection).

In the grid, click the Type cell and type part of the name (tyler gt, christie a) instead.

[[img truss-grp-truss.jpg|The Truss section.|100]]

Setting the length

A truss line is its truss pieces plus any corner blocks in the line:

  • Truss pieces - the total length of truss sections, not counting corner blocks. Type it (30, 28-6).
  • The line under the fields adds it up: 30 ft truss + 2 ft corner blocks = 32 ft whole line. With add block lengths ticked (the default) each corner block's length is added to the pieces. Untick it if the length you typed already includes the blocks.

Building a truss from standard pieces

Click Build from pieces… to assemble the line from stock lengths. Buttons such as +10' and +5' add a stick of that length (the lengths offered depend on the truss family); type another length in the small box and click + add for an odd piece (the app remembers it for next time). Each piece is shown as a tag - click a tag to remove that piece. +CB between two tags puts a corner block between those pieces. Type a length instead goes back to a single length.

[[img pieces-builder.jpg|A truss built from pieces.|100]]

Corner blocks in a truss line

Open the Corner blocks section. First choose the Block to add - maker, truss family and block (with its number of ways and weight). The app suggests a block that fits the truss.

The line is summed up as, for example, 8' + CB + 13' + CB + 9' = 32 ft. Blocks are named after the truss (North CB1, North CB2…); Number blocks from with Renumber this truss or Renumber all trusses renames them in order along each line.

Placing a free truss

A truss that is not bolted to anything is free. Place it in any of these ways:

  • Type Plan X, Plan Y (the start point) and Angle in the Placement section, or in the grid's X, Y and Angle columns. Angles: 0 = east, 90 = north, 180 = west, 270 (or -90) = south.
  • Drag it on the plan. It moves in half-foot steps, and its ends snap to the ends of other trusses within 1.5 ft; hold Alt while dragging to stop the snapping.
  • Press R (or click ⟳) to turn the selected truss 90° anticlockwise about its start.

To move a whole rig so it is centred on the origin, use Center on 0,0 in Rig settings.

Bolting a truss to a corner block

Bolting joins two trusses: the truss you bolt is placed by the block, at right angles to the block's truss, and follows it from then on.

  1. Make sure the corner block exists: it must be in another truss's line (see above).
  2. Select the truss you want to bolt on. In Placement › Bolt to a corner block, check the two options (the defaults are usually right):
    • end: automatic, its start meets the block, its end meets the block, or the block is along it (the block sits partway along this truss, as where a truss passes through a block);
    • direction: automatic or extends north / south / east / west - which way the truss runs from the block.
  3. Click Bolt to… (in the Placement section or at the top of the panel). A blue bar appears: Bolt North: click a corner block, and the corner blocks you can use are outlined.
  4. Click the corner block on the plan. The truss jumps into place. (Press Esc or Cancel to stop without bolting.)
[[img pick-mode.jpg|Choosing a corner block to bolt to. The blocks you can pick are outlined in blue.|80]]

You can also start from the block: select a corner block and click Bolt a truss here…, then click the truss; or click one of the block's free faces (+ north, + east…) and then the truss, to bolt it to that face.

Once bolted, the Placement section says, for example, Bolted to West CB1 at its start, extends east, and offers:

  • Flip side - swing the truss to the other side of the block's truss;
  • Bolt other end - use the other end of this truss at the block;
  • Unbolt - make it free again (it stays where it is).

Its X, Y and angle are now grey (set by the block). To move it, move the truss that owns the block.

[[img truss-grp-place.jpg|The Placement section of a bolted truss.|55]]

Closing a box: bolting both ends

A truss can be bolted at both ends. After a truss is bolted at its start, bolt its end to a corner block on another truss: that other truss (if it is free) is pulled onto this truss so the block meets its end. Its panel then says Pulled onto North (bolted through its own corner block), with Flip side and Unbolt. This is how the last side of a box closes onto the first - see Building a box, step by step. If the lengths around a loop do not add up, the app warns that the truss does not meet the block and by how much.

Bolted parts must match

Bolted truss and corner blocks only fit within one manufacturer's truss family (JTE 12x12 does not bolt to Christie A Type, even at the same size). The app warns, and draws the bolt in red on the plan, when bolted parts do not match - including a generic or universal truss bolted to branded parts. Parts it cannot check (generic, universal, custom) get a note. Trusses stacked or clamped at a crossing can be any family. Nothing is ever blocked; it is a warning.

Stacking or clamping at a crossing

Where two trusses cross on the plan, one can rest on top of the other or be clamped underneath it without a corner block. In Placement › Stack or clamp at one point, choose sits above or clamped below, choose the other truss, and click Add. The app adds a support where the two centerlines cross: this truss is then held up by the other truss at that point.

Bolted connections table

Every bolt and stacking point is a support of the truss, listed under Hoists & connections › Bolted connections. For each one you can see and change where it is on this truss (At … from), which truss or block it is joined to and where on it, whether it is in the same plane, above or below, a hardware weight at the connection (+lb), and the force passed through it. The plan tick keeps both distances tied to the plan drawing; typing a distance unticks it. Delete removes the connection.

UDL and cable allowance

  • UDL - a total weight spread evenly along the whole truss, for example a drape, a projection screen or an LED wall hung along it. Type the total (not per foot).
  • Cable - cable weight per foot (lb/ft) on this truss, added to its UDL. Blank uses the rig's cable allowance (Rig settings); 0 means no cable on this truss. The panel shows the result, e.g. Cable allowance 1.5 lb/ft × 32 ft = 48 lb, added to the UDL.

Duplicating and deleting

Duplicate makes a free copy called … copy, a little below and to the right of the original, with the same type, pieces, loads and hoists. The copy is not bolted to anything and has no corner blocks or bolted connections - add those again.

Delete (or Delete with the truss selected) removes the truss after asking. Its corner blocks go with it; trusses that were bolted to it or to its blocks stay where they are but are no longer bolted (and show Not solved if that was their only support), and hoists hung below it hang from the structure again. Undo brings it all back.

Corner block panel

Click a corner block (on the plan, in the outline, or select in its truss's list) to open its panel.

  • Faces - a diagram of the block with the truss on each face (north is up the plan) and how many of its ways are used. Click a free face, then a truss, to bolt that truss to that face. Too many faces means more trusses are bolted to it than it has ways.
  • Block - the block type (maker › family › block); Hardware fitted for blocks sold with different plates; a Weight override (leave blank for the published weight - and enter one where the maker publishes none); its Height in 3D; and a link to the maker's product page.
  • Carrying - the loads passed into it by the trusses bolted to it.
  • Supports - a hoist can hang directly on a corner block: open Supports and click + Add hoist.

Remove from … takes the block out of its truss line.

Building a box, step by step

This example builds a simple box: two 22 ft sides (West and East, each 20 ft of truss with a corner block at each end) and two 30 ft sides (North and South) bolted between them, hung from four hoists, one at each corner. It uses the default truss (JTE 12x12 Plated) and the default 6-way corner block. (For a larger example, open File › Load example box and click each truss to see how it is built.)

The two short sides

  1. File › New rig. Click + Truss. Rename it West. Set Truss pieces to 20 and Angle to 270 (it now runs south from X 0, Y 0).
  2. Open Corner blocks and click + Corner block at start, then + Corner block at end. The line reads 20 ft truss + 2 ft corner blocks = 22 ft whole line, and the blocks are West CB1 (north end) and West CB2 (south end).
  3. Click + Truss again. Rename it East, Truss pieces 20, Angle 270, Plan X 40 (anywhere to the east will do - it is pulled into place later). Add a corner block at its start and its end (East CB1, East CB2).

The long sides

  1. Click + Truss. Rename it North, Truss pieces 30.
  2. In Placement, set the options to its start meets the block and extends east. Click Bolt to… and click West CB1 on the plan. North jumps to the north-west corner and runs east.
  3. Set the option to its end meets the block, click Bolt to… again and click East CB1. East is pulled across so its north block meets North's end: the box has three sides.
  4. Add South the same way: + Truss, 30 ft; its start meets the block, extends east, Bolt to… West CB2; then its end meets the block, Bolt to… East CB2.

Loads and hoists

  1. Press 2. Add some loads - for example select North, type 80 lb @ -5 in the quick-add box of its Loads section, press Enter and click Mirror all; do the same on South.
  2. Press 3. Put a hoist at each corner: on West and on East, add hoists at 0.5 from the start and 0.5 from the end (the centres of the corner blocks). In the grid, type the position in At and set From to start or end.
  3. Press 4 and check the results. With 80 lb moving lights (two per side, mirrored) each corner hoist carries about 382 lb.
[[img box-built.jpg|The finished box: four sides joined at four corner blocks, a hoist at each corner.|85]]
Why a hoist at every corner?

Some manufacturers (for example Christie Lites for its A Type) require a box built with 90° corner blocks to be supported at every corner, and allow only part of the truss capacity where an unsupported block joins four or more sections. The app warns about both. Always follow the maker's rules for its corner blocks.
